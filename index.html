          Clé de recherche YouTube

          Pour chercher directement dans l'autoradio, il faut une clé gratuite de Google. Elle reste sur cet iPhone. À faire une seule fois, environ 5 minutes :

          1. Ouvre console.cloud.google.com et connecte-toi avec ton compte Google.
          2. Crée un projet, par exemple « Route sans fin ».
          3. Dans « API et services », puis « Bibliothèque », active YouTube Data API v3.
          4. Dans « Identifiants », touche « Créer des identifiants », puis « Clé API ».
          5. Modifie la clé : dans « Sites Web », ajoute . Dans « Restrictions relatives aux API », choisis YouTube Data API v3.
          6. Copie la clé et colle-la ci-dessous.
